# Final manuscript numbering

This repository accompanies the submission version of
*Asymptotically Optimal Online Selection of a Large Voronoi Cell*.

The mathematical computations in `verify.py` are unchanged from the earlier
draft. The following label changes identify the corresponding results in the
final submission manuscript:

| Earlier label | Final manuscript label |
|---|---|
| Lemmas 2.1 / 2.2 | Lemmas 3.1 / 3.2 |
| Proposition 2.5 | Proposition 3.5 |
| Theorem 3.2 | Theorem 4.2 |
| Lemma 4.1 (concavity) | Lemma 5.1 |
| Corollary 4.3 | Corollary 5.3 |
| Lemma 4.4 | Lemma 5.4 |
| Theorems 4.5 / 4.6 / 4.7 | Theorems 5.5 / 5.6 / 5.7 |
| Remark 4.8 | Remark 5.8 |
| Proposition 4.9 | Proposition 5.9 |
| Remark 4.10 | Remark 5.10 |
| Lemma 5.1 (E[Y] scaling) | Lemma 6.1 |
| Lemma 5.4 (one-hit/two-hit) | Lemma 6.4 |
| Theorem 5.5 | Theorem 6.5 |
| Theorem 5.6 (universal barrier) | Theorem 6.6 |
| Theorem 6.4 (hidden-tile construction) | Theorem 7.4 |
| Lemma 6.10 | Lemma 7.10 |
| Proposition 6.11 | Proposition 7.11 |
| Section 6 (predetermined-site construction) | Section 7 |

The equation numbers in the final manuscript are likewise shifted with their
sections: the square-cell formulas are in Section 5, the two-hit formulas are in
Section 6, and the predetermined-site construction is in Section 7.

No floating-point approximation is used in a proof-critical comparison. Monte
Carlo and numerical experiments in the script are labelled as consistency tests,
not proofs.
